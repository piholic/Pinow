# PiNow — 오늘 파이를 받는 매장 지도

**PiNow**는 실시간 체크인 기반으로 파이(Pi)를 받는 가맹점을 지도에서 보여 주는 웹 프로토타입입니다.
Pi Next Hackathon을 위해 만들었고, 단일 HTML 파일로 동작합니다.

**라이브 데모:** https://piholic.github.io/Pinow/

## 무엇을 하는 앱인가

- **손님 · 점주 두 모드** — 앱을 처음 열면 **바이어(손님)로 입장** / **셀러(점주)로 입장**을 고릅니다. 고른 모드는 기억되어 다음 방문부터 바로 열리고, 상단 바에서 언제든 바꿀 수 있습니다.
- **오늘 체크인한 매장 지도** — 파이 결제를 받는 매장이 오늘 문을 열고 체크인하면, 지도에서 바로 찾아갈 수 있습니다.
- **체크인** — 매장주가 오늘 영업 중임을 한 번의 탭으로 알립니다. 체크인은 하루가 지나면 자동으로 만료됩니다.
- **매장 상세** — 오늘 체크인 상태, 주소, 취급 품목을 **현지어와 영어 두 줄**로 보여 주고, 테스트넷 Pi 결제와 방문 인증을 할 수 있습니다.
- **주변 매장 검색** — 매장 이름·주소·품목을 한국어로도 영어로도 검색합니다.
- **광고 없음** — 광고 시청 보상 없이 체크인·방문 인증 포인트가 바로 지급됩니다.
- **정직한 빈 상태** — 반경 안에 체크인한 매장이 없으면 "가까운 매장이 없습니다"를 분명히 보여 주고, 가장 가까운 매장까지의 거리를 안내합니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI, 지도, 상태 관리, 샘플 데이터) — 단일 파일, 빌드 없음 |
| `spec.md` | 제품 스펙: 화면, 데이터 모델, 상태 전이, 엣지 케이스 |

## 실행

`index.html`을 브라우저에서 열면 됩니다. 지도 타일은 OpenStreetMap, 지도 렌더링은 Leaflet(CDN)을 사용하며,
샘플 데이터는 파일 안에 들어 있어 서버나 API 키가 필요 없습니다.

## 배포 (GitHub Pages)

이 저장소는 GitHub Pages로 `gh-pages` 브랜치의 루트를 그대로 게시합니다(빌드 과정 없음, `.nojekyll` 포함).

```bash
git push origin main          # 소스 브랜치
git push origin main:gh-pages # 게시 브랜치 — 이 push가 사이트를 다시 배포합니다
```

`main`만 올리면 사이트는 갱신되지 않습니다. 위처럼 `gh-pages`도 함께 올려 주세요.

## 샘플 데이터에 대한 안내

데모용 샘플 데이터이며 실제 파이 네트워크의 매장 정보가 아닙니다.
